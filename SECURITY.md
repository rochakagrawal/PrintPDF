# Security Policy

## Supported versions

Security fixes are provided for the latest published version of PrintPDF.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/rochakagrawal/PrintPDF/security/advisories/new).
Do not disclose the vulnerability in a public issue before a fix is available.

Include the affected PrintPDF and macOS versions, steps to reproduce, expected
impact, and any suggested mitigation. Use synthetic test documents and remove
personal paths, account names, credentials, and document contents from logs or
screenshots. Do not attach a real confidential PDF.

Reports should receive an acknowledgement within seven days. Updates will be
provided as investigation progresses, and public disclosure will be
coordinated after a fix or mitigation is ready.

## Scope

Security issues include unintended document disclosure, unsafe file handling,
privilege-boundary problems in installation or printing, and unauthorized file
overwrites. General support requests and ordinary bugs can use GitHub Issues.
