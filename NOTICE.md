# Attribution and modifications

PrintPDF is a modified version of RWTS PDFwriter 3.1d.

Original work:

- RWTS PDFwriter © 2016–2023 Rodney I. Yager
- Lisanet PDFWriter by Simone Karin Lehmann
- CUPS-PDF project

PrintPDF modifications, August 2026:

- Renamed the user-facing printer and utility to PrintPDF.
- Replaced the fixed personal destination with a per-user folder chooser.
- Added per-user destination persistence and a configurable background mover.
- Added collision-safe movement without overwriting existing PDFs.
- Removed personal usernames and cloud-provider-specific paths.
- Raised the minimum supported system to macOS 12.
- Added isolated, unsigned local build support for current Xcode releases.
- Updated installer, uninstaller, documentation, identifiers, and paths.
